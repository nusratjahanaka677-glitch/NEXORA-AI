# NEXORA AI v2 Starter
Includes a single dashboard, central prompt area, local image preview, Studio navigation, local project saving, and a Node/Express starter backend.
IMPORTANT: This is a foundation, not a complete AI generator. Real AI generation, image understanding, 3D/game/video generation, authentication and deployment still need implementation. Keep API keys in private server environment variables only; never in browser files or GitHub.
Run: npm install && npm start ; then open http://localhost:3000
A private source repository does not make a deployed site private. Add authentication before exposing a deployment.
